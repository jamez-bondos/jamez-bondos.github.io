这是一篇短占位文章，用来和长篇样式文章一起检查主页列表密度。

## 延迟由什么组成

端到端延迟可以粗略拆成排队、预填充、逐 token 解码和网络传输。真正的瓶颈需要测量，而不是从单个算子直接推断。

### 首 token 延迟

首 token 延迟通常更受输入长度、批处理策略和调度等待影响。

### 生成吞吐

稳态生成更关心内存带宽、KV Cache 布局和并发请求之间的资源竞争。

## 一个简单原则

先固定工作负载和硬件，再比较实现；否则吞吐数字没有可比性。
